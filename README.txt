Tweet Congress — Ready-to-host package

Files:
- index.html — main entry page.

Hosting:
1. Upload index.html to your hosting public_html / www / root folder.
2. Make sure the filename remains exactly "index.html".
3. Open your domain.

Important:
The uploaded archived source contains the original application's HTML shell and a
reference to a JavaScript bundle, but the actual bundle was not present in the
uploaded file. Therefore this package is a clean standalone version, not a full
reconstruction of the original interactive application.
